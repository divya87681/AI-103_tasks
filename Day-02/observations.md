# Day 02 - Intent-Related Text Analysis

**Service:** Azure AI Language

**Status:** NOT VERIFIED - No live Azure AI Language request has been demonstrated.

## 1. Problem Statement

Extract key phrases and entities from fictional employee-support text and compare a simple rule-based classification heuristic against supported Azure AI Language features.

## 3. Shortlisted Use Cases

1. **IT support:** Identify key phrases and synthetic incident identifiers in support requests.
2. **HR leave queries:** Extract relevant phrases from leave-related questions.
3. **Finance text:** Identify invoice and payment-related terms.
4. **Access problems:** Recognise account and password-related language.
5. **Incident tracking:** Preserve fictional identifiers for later processing.

### Selected Problem and Justification

The selected problem is intent-related analysis of fictional employee-support text. It allows comparison between simple keyword heuristics and Azure AI Language features such as key phrase extraction and named entity recognition.

## 4. Architecture

Input text -> Input validation -> Analysis adapter -> Key phrase and entity results -> Rule-based heuristic comparison -> JSON output.

The local adapter is the default and makes no network requests. Live mode requires an endpoint, key, and explicit opt-in.

## 5. Request and Response Schema

### Example request

{
  "text": "My laptop is broken and I cannot access the payroll system for EMP-104"

This response is generated by local rules. It is not an Azure API response.

## 6. Security Boundary

- Use fictional text and identifiers only.
- Keep endpoint credentials out of source code and Git commits.
- Read credentials from environment variables.
- Do not enable live requests without explicit approval.
- Avoid logging credentials or confidential text.
- Validate responses before processing them.
- Do not treat heuristic categories as authoritative intent predictions.

## 7. Expected Errors

- Empty or whitespace-only text
- Non-string input
- Missing endpoint or key in live mode
- Live requests not explicitly approved
- HTTP or authentication failure
- Invalid JSON or unexpected API response
